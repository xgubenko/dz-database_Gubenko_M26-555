используйте команду, чтобы собрать пакет и убедиться, что вы его правильно настроили
uv build

Проверьте метаданные собранного пакета без публикации, с помощью twine (запустите его через uvx, не устанавливая постоянно в проект):
uvx twine check dist/*
 
Активируйте виртуальное окружение
source .venv/bin/activate

Установите пакет из собранного дистрибутива и убедитесь, что команда project работает вне режима разработки. Самый uv-нативный способ — установить его как изолированный CLI-инструмент:
uv tool install dist/*.whl

Убедитесь, что команда работает, запустив project в терминале.
project
