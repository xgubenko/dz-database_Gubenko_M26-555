## Запуск проекта

Запустить модуль проекта:

```bash
uv run python -m primitive_db.main
```

Запустить CLI-команду в окружении проекта:

```bash
uv run project
```

## Управление таблицами

### Создание таблицы

Введите команду через пробел в следующем формате:

```text
create_table <имя_таблицы> <имя_поля>:<тип> [...]
```

- `create_table` — команда создания таблицы.
- `<имя_таблицы>` — название таблицы.
- `<имя_поля>:<тип>` — название поля и его тип, разделённые двоеточием.
- Поддерживаемые типы данных: `str`, `int`, `bool`.
- Можно указать несколько полей, разделяя их пробелами.

**Пример:**

```text
create_table users name:str age:int active:bool
```

Эта команда создаст таблицу `users` с тремя полями: `name` типа `str`, `age` типа `int` и `active` типа `bool`.

### Удаление таблицы

Введите команду через пробел в следующем формате:

```text
drop_table <имя_таблицы>
```

- `<имя_таблицы>` — название таблицы.

**Пример:**

```text
drop_table users
```

Эта команда удалит таблицу `users`.


## Сборка пакета

Соберите пакет, чтобы проверить корректность его конфигурации:

```bash
uv build
```

В результате в каталоге `dist/` появятся собранные дистрибутивы пакета.

## Проверка метаданных пакета

Проверьте метаданные собранных дистрибутивов с помощью `twine`, не устанавливая его в проект:

```bash
uvx twine check dist/*
```

## Установка и проверка CLI-команды

Установите пакет из собранного wheel-дистрибутива как изолированный CLI-инструмент:

```bash
uv tool install dist/*.whl
```

Проверьте, что команда `database` работает после установки:

```bash
database
```

> Примечание: команда `uv tool install` устанавливает инструмент в изолированное окружение. Активировать `.venv` для этого не требуется.

## Ruff

### Проверка всего проекта

```bash
uv run ruff check .
```

### Проверка отдельного файла

```bash
uv run ruff check path/to/file.py
```

Замените `path/to/file.py` на путь к проверяемому Python-файлу.
